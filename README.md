# iakaFleet

Vue **en lecture seule** de la flotte de sessions Claude Code : un agent par machine publie
l'etat des sessions sur MQTT, une console CLI (`iakafleet ls|watch`) le lit.

- Vision et decisions : `specs/PROJET.md`
- Instruction du MVP : `specs/instructions/mvp-vue-flotte-lecture-seule.md`
- Installation : `docs/installation.md`

```bash
npm install
npm test
npm run lint
```
